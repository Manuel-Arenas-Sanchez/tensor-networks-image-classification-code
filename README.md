# Tensor Networks for Image Classification

Repositorio de trabajo para desarrollar el código y los experimentos de un futuro artículo científico.

Parte del código del [Trabajo Fin de Grado original](https://github.com/Manuel-Arenas-Sanchez/Tensor-Network-Model-In-Deep-Learning), que se conserva como referencia histórica. El desarrollo del artículo continuará en este repositorio.

## Estado

Proyecto en preparación. Los objetivos, los experimentos y el alcance del artículo están pendientes de definición.

## Contenido

- `src/tn_dl/`: implementación de los modelos y del flujo de entrenamiento y evaluación.
- `configs/`: configuraciones de los experimentos.
- `scripts/`: scripts auxiliares.
- `tests/`: pruebas del código.

Las instrucciones de instalación, preparación de datos y reproducción de resultados se actualizarán conforme se concrete el trabajo.
